# Module B 온톨로지 정의서

## 1. 목적
이 온톨로지는 Module B가 금융 및 산업 관련 텍스트에서 구조화된 지식을 추출하기 위해 사용하는 최소한의 엔티티 유형과 관계 유형을 정의한다.

버전 1의 목표는 모든 정보를 다 추출하는 것이 아니다.
Graph RAG에 실제로 유용하고, 일관되게 뽑을 수 있는 정보만 먼저 추출하는 것이 목표이다.

## 2. 엔티티 유형

### 2-1. Company
정의:
금융 또는 산업 활동에 참여하는 기업, 법인, 스타트업, 기관 등

필수 필드:
- id
- type
- name

선택 필드:
- stock_code
- country
- industry

예시:
- 카카오
- 삼성전자
- 네이버

### 2-2. Person
정의:
기업 또는 사건과 관련되어 언급되는 인물. 예: 대표이사, 임원, 창업자, 주요 인사

필수 필드:
- id
- type
- name

선택 필드:
- role
- affiliated_company

예시:
- 김범수
- 이재용

### 2-3. Event
정의:
인수, 투자, 선임, 제휴, 조직 개편 등 의미 있는 비즈니스/금융 이벤트

필수 필드:
- id
- type
- name

선택 필드:
- event_type
- date
- description

예시:
- 카카오의 A사 인수
- 삼성전자 조직개편
- 네이버 투자 발표

### 2-4. Industry
정의:
기업 또는 사건과 연결되는 산업 분야 또는 사업 도메인

필수 필드:
- id
- type
- name

선택 필드:
- description

예시:
- AI
- 클라우드
- 반도체
- 바이오

## 3. 관계 유형

### 3-1. ACQUIRES
의미:
한 기업이 다른 기업을 인수함

허용 방향:
Company -> Company

예시:
카카오는 A사를 인수했다.

### 3-2. INVESTS_IN
의미:
한 기업이 다른 기업 또는 사업체에 투자함

허용 방향:
Company -> Company

예시:
네이버는 B사에 전략적 투자를 진행했다.

### 3-3. APPOINTED_TO
의미:
한 인물이 특정 기업의 직위에 선임됨

허용 방향:
Person -> Company

예시:
홍길동은 카카오의 대표이사로 선임되었다.

### 3-4. AFFILIATED_WITH
의미:
한 인물이 특정 기업에 소속되거나 연관되어 있음

허용 방향:
Person -> Company

예시:
김철수는 삼성전자 부회장이다.

### 3-5. BELONGS_TO
의미:
한 기업이 특정 산업 분야에 속함

허용 방향:
Company -> Industry

예시:
삼성전자는 반도체 산업에 속한다.

## 4. 공통 엔티티 규칙
- 모든 엔티티는 고유한 id를 가져야 한다.
- 모든 엔티티는 type을 가져야 한다.
- 모든 엔티티는 사람이 읽을 수 있는 name을 가져야 한다.
- 가능하면 공식 한국어 명칭을 사용한다.
- role을 별도로 저장하는 경우, person의 name에는 직함을 넣지 않는다.
- 날짜는 가능한 경우 YYYY-MM-DD 형식을 사용한다.
- 불확실한 정보는 임의로 생성하지 않는다.

## 5. 공통 관계 규칙
- 모든 관계는 type을 가져야 한다.
- 모든 관계는 from과 to를 포함해야 한다.
- 모든 관계는 근거 문장 evidence를 포함해야 한다.
- 이 문서에 정의된 관계 유형만 사용한다.
- 텍스트 근거가 불분명하면 관계를 생성하지 않는다.

## 6. 엔티티 ID 규칙
권장 형식:
- company_{정규화된이름}
- person_{정규화된이름}
- event_{짧은이름}
- industry_{정규화된이름}

예시:
- company_kakao
- company_samsung_electronics
- person_kim_beom_su
- industry_ai

## 7. LLM 추출 규칙
엔티티와 관계를 추출할 때 다음 규칙을 따른다.
- 이 문서에 정의된 엔티티 유형만 사용한다
- 이 문서에 정의된 관계 유형만 사용한다
- 반드시 유효한 JSON만 반환한다
- 모든 관계에는 근거 문장을 포함한다
- 텍스트 근거가 부족한 엔티티/관계는 생략한다
- 없는 사실을 추측해서 만들지 않는다

## 8. 버전 1 제한사항
이 온톨로지는 의도적으로 작은 범위로 시작한다.

버전 1에서 아직 다루지 않는 항목:
- 자회사 관계
- 지분율
- 제휴 강도
- 세부 계약 구조
- 여러 문서에 걸친 타임라인 연결
- 다양한 출처 간 별칭 통합

## 9. 예시
입력 문장:
카카오는 2026년 3월 20일 A사 인수를 발표했다. 이번 결정은 AI 사업 강화를 위한 전략의 일환이다.

예상 엔티티:
- Company: 카카오
- Company: A사
- Industry: AI
- Event: 카카오의 A사 인수

예상 관계:
- 카카오 ACQUIRES A사
- 카카오 BELONGS_TO AI
